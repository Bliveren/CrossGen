# Code of Conduct

## Our Standard

CrossGen is a community project for people building local-first image workflows.
Participants are expected to be respectful, specific, and constructive. We
welcome questions, bug reports, documentation improvements, provider adapters,
and workflow examples from people with different backgrounds and experience
levels.

Unacceptable behavior includes harassment, discrimination, personal attacks,
deliberate disruption, publishing private information, credential exposure, and
spam or artificial engagement such as bought stars or coordinated vote
manipulation.

## Scope and Enforcement

This code applies in GitHub issues, pull requests, discussions, the Discord
community, and other spaces where someone represents the CrossGen project.
Project maintainers may edit or remove content, close discussions, or restrict
participation when necessary to protect the community.

Report a safety concern privately through the CrossGen maintainers or the GitHub
Security Advisory channel for security issues. Do not include API keys, private
images, local state, or other sensitive data in public reports.

This document is adapted from the Contributor Covenant principles and is kept
intentionally concise so contributors can find the expectations quickly.
