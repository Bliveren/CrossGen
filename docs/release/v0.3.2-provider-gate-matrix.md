# CrossGen v0.3.2 Provider Gate Matrix

> Status: template for v0.3.2 release candidates  
> Purpose: prove image task reliability and diagnostics by operation, route, model, timeout, and output.

## Rules

- Do not record API keys or full private Base URLs.
- Record provider kind and route behavior, not a specific aggregator brand.
- Text-to-image success does not prove image-to-image support.
- Image-to-image success does not prove guided-region/mask support.
- User-configured timeout must be honored. If a task times out, record the configured timeout and elapsed seconds.
- A failed gate can pass release only when the product surface shows a correct diagnostic and a usable next action for an unsupported or provider-limited operation.

## Required Fields

For every run, record:

- Date and tester.
- Commit SHA and package artifact identity.
- Platform.
- Provider kind: `openai`, `openai-compatible`, `gemini`, or `custom`.
- Base URL type: official, compatible gateway, local mock, or other redacted category.
- Model id.
- Operation: text-to-image, image-to-image, guided-region edit.
- Route selection: auto, chat-completions, responses, image-api.
- Resolved route.
- Input image count.
- Mask: yes/no.
- Timeout seconds.
- Attempt count.
- Elapsed seconds.
- Result: success, failed as expected, failed unexpectedly.
- Output count and saved asset ids if successful.
- Diagnostic category if failed.
- User-visible next actions if failed.

## Failure Classification Checklist

Use the normalized category that best matches the user-facing cause:

- `auth`: invalid or missing key.
- `billing`: insufficient balance, quota exhausted, payment required.
- `rate_limit`: provider rate limit or concurrency rejection.
- `timeout`: user timeout reached.
- `safety`: content safety or moderation block.
- `unsupported_capability`: model does not support reference/edit/mask.
- `route_unsupported`: endpoint path or route does not support the operation.
- `provider_empty_output`: provider returned no saveable image, including `data: null`.
- `provider_schema`: provider returned a malformed or incompatible response shape.
- `network`: network or DNS failure.
- `cancelled`: user or worker cancellation.
- `unknown`: only when no clearer category is possible.
