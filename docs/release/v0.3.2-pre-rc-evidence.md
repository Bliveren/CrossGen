## Scope

This evidence records Round 4 preparation work before creating a `v0.3.2-rc.1`
candidate package. It does not approve a final release.

## Added Gate Support

- Added `pnpm verify:real-provider-gate`.
- The runner targets compatible chat-completions-style image routes.
- Added `pnpm verify:real-crossgen-gate`.
- The CrossGen runner is preferred for RC validation because it exercises the
  saved provider configuration through the real CrossGen CLI queue path instead
  of requiring API keys in the shell environment.
- It records operation-level evidence for:
  - OpenAI-compatible text-to-image.
  - OpenAI-compatible image-to-image.
  - OpenAI-compatible guided-region with mask input.
  - Gemini-compatible text-to-image.
  - Gemini-compatible image-to-image.
- It writes structured `summary.json` evidence under `real-api-artifacts`.
- It redacts API keys and does not write full private Base URLs.
- It refuses to make real API calls unless explicit cost acceptance is set.
- It also supports `CROSSGEN_REAL_PROVIDER_DRY_RUN=1` for no-cost saved-config
  preflight without submitting generation jobs.

```bash

CROSSGEN_REAL_PROVIDER_API_KEY="<redacted>" \
```
