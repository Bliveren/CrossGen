This preflight is the execution record for the v0.3.5 candidate. It does not
authorize a public release. The exact candidate commit, deterministic
verification, platform package evidence, real AIHub gate, and product-owner
acceptance must be recorded in `docs/release/evidence.json` before publication.

(27 gates, all passed). Every v0.3.5 gate restarts as `pending` because the
release artifact changed; prior evidence is reference material only and cannot
be reused as v0.3.5 release evidence.

## Candidate scope

- v0.3.4 已发布能力回归：AppLink provider import、media foundation、managed
  media root、media-aware viewer、CLI/MCP 媒体 metadata。
- 模型发现证据契约：`listed` / `confirmed` / `inconclusive` / `rejected`
  四态；GPT Image 2 与 GPT Image 2.5 按精确 provider model id 区分；display
  name 与裸 `gpt-image-2.5` 兼容别名不构成 provider 证据；AppLink 模型提示
  仅用于初始化。
- Sketch 工作区：图生图参考区与 Input Studio 融合、capability preflight、
  部分历史隔离、packaged Electron 矩阵与 feature-flag 回滚。
- Gemini 图像模型契约规范化与 POSIX `crossgen` 启动器符号链接修复。
- General 图生图（新增范围，2026-10-05）：OpenAI 兼容 General 兜底在
  路由确认后支持参考图编辑；未确认时保持 prompt-only 并给出可诊断原因。
  Mask/inpaint、Sketch 和 Responses 多轮语义仍不在 General 范围内。
- 视频技术预览（Phase 2 之后）：单路线、单模型样机，submit / poll /
  download / poster / postprocess / preview / cleanup 最短链路。

Not included: 完整视频产品、时间轴编辑、批量变体、多 provider 视频矩阵、
视频生成 GA、绕过 AIHub 的默认真实 provider gate。

| Probe | Result |
| --- | --- |
| `GET /models/gpt-image-2.5-sunburst` | HTTP 200 with `model_not_found` (metadata inconsistency) |

confirmed, not rejected). Consequences:

  fails, and no Gemini image model is listed.

  listed rows can produce output; it failed upstream, returned no image, and is
  disclosed in the evidence file. Provider billing could not be confirmed from
  the API response.

## Rollback

- 任何视频能力必须可通过 feature gate 关闭。
- Sketch 继续通过 `CROSSGEN_SKETCH_ENABLED` 提供 packaged 回滚。
- 模型发现证据契约若阻塞启动模型选择，必须能回退到上一次成功的探测结果，
  且不得静默启用未经精确 id 确认的模型。
- 任何 gate 未通过时，`docs/updates/latest.json` 继续指向已批准的 v0.3.4。
