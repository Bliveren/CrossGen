  preview, model discovery reuse, and macOS/Windows/Linux launch handling.

  temporary cleanup, Gallery media scanning, and media-aware viewer boundaries.

  artifact recovery, packaged Electron validation, and feature-flag rollback.

Not included: real video generation, ffmpeg packaging, timeline editing, GIF
export productization, or new video MCP tools.

## Rollback

- AppLink 解析或确认失败时不写入 provider state。
- media root 迁移失败时不更新 `storage.mediaRoot`，源目录保留。
- 视频/GIF 预览失败时提供下载/打开目录动作，不影响图片 Canvas。
- 若候选包出现图片回归，停止发布并回退到上一个已批准的 release。

## Local launch hygiene

- Replacing a packaged `app.asar` does not update an already-running Electron
  process. Quit all CrossGen processes before reopening a rebuilt candidate.
- For local candidate inspection, launch the explicit package path
  `release/mac-arm64/CrossGen.app`; do not infer the loaded version from a
  process path that may belong to an older process.
- The user-level `~/.local/bin/crossgen` launcher must resolve to the same
  candidate package. An older `/Applications/CrossGen.app` can remain installed
  for rollback, but it must not be the active debug entry.
- `http://localhost:5174/` is not CrossGen on this machine; it is owned by the
  separate Corgnitor Management Vite project. CrossGen source preview uses the
  repository's own dev-server command and port.
